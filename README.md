# Solveur CFD à deux dimensions

Ce CFD permet de trouver les frottements de l'eau par rapport à un objet qui le traverse

Ce calcul permet de trouver une solution plus éfficace aux calculs de frottements expérimentaux nécessaire à notre TM.


Naviguez au fichier src pour voir les fichiers C++ executables, et include pour les fichiers en-têtes.

Installez euler_method2D.exe pour pouvoir le tourner sur votre ordinateur.

Pour le tourner, vous devrez aller sur la console de votre  ordinateur et inscrire le chemin de ce fichier.

Par Exemple: "C:\Users\Votre nom\Coding\C++\Road to CFD\Fluid Solver\out\build\x64-release\euler_method2D.exe"

Normalement vous pouvez le copier sur votre Finder ou File Explorer.
